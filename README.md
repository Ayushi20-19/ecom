## Getting Started
1. **Clone the repository:**  
   ```bash
   git clone https://github.com/Ayushi20-19/ecom.git
   ```
2. **Install dependencies:**  
   ```bash
   npm install
   ```
3. **Start the server:**  
   ```bash
   npm start
   ```
